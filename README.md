# Global Temperature Analysis

This project aims to analyze global temperatures and their changes across centuries.

## Project Structure

Here is the structure of this project:

|- notebooks/
    ...
   |- archive/
|- src/
|- README.md
|- data/
   |- raw/
   |- processed/
   |- cleaned/


## Directory Descriptions

- **notebooks/**: Contains Jupyter notebooks used for data analysis and exploration.
  - **archive/**: Includes notebooks that are no longer useful.
  
- **src/**: Contains source code for data processing and analysis.

- **data/**: Contains the data used in the project.
  - **raw/**: Raw (unprocessed) data.
  - **processed/**: Processed data ready for analysis.
  - **cleaned/**: Cleaned and sanitized data.
